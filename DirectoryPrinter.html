DirectoryPrinter

Print all your sub (and subsub etc.) directories and files.

Usage
  • Execution:
    • Download the jar file.
    • Go to the directory of the downloaded jar file.
    • Run "java -jar directoryprinter.jar "
  • Output: An html file with a list of your directories and files, starting from the given directory. The output file is saved in the given directory.
Example
  • Command Line: java -jar directoryprinter.jar c:\users\yoni\ws\yoni-site
  • Output: directory_listing.html
